# Default pack

the content type subfolders are mostly arbitrary, and are intended for organisational purposes. if you don't care about that, just throw everything in `common`.
- item ids are `modNamespace.folder.fileName` so lazy mode would be `nameSpace.common.fileName`

standard folders are the following:
```
  "common",
  "character",
  "ground",
  "tile",
  "dimension",
  "biome",
  "item",
  "mob",
  "worldgen",
  "font",
  "ui"
```
